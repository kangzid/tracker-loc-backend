## 💡 KEY POINTS

1. **Polling:** Frontend polling setiap 30 detik untuk check new notifications

3. **Hard Delete:** Superadmin delete = hilang untuk semua orang + image dihapus
4. **Image:** Support jpeg|png|jpg|webp, max 5MB, auto-cleanup on hard delete
5. **Token:** Gunakan Bearer token dari localStorage saat API call
6. **Components:** 10 components siap, tinggal copy-paste & customize
